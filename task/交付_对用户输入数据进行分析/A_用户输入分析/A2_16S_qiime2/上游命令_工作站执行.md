# A2 上游 QIIME 2 命令——工作站/WSL 执行（Windows 本机不可装，见下）

## 为什么本机不跑 QIIME 2 框架
QIIME 2 官方发行版仅提供 Linux/macOS 的 conda 包，Windows 无原生支持
（官方安装文档 https://docs.qiime2.org/2024.10/install/ ；Windows 官方建议 WSL2/虚拟机）。
本机无 conda/WSL 权限与环境，框架安装属 [受阻]。**但** artifacts 的读取与下游分析
（thetaverse）已在 Windows 本机用真实 qza 验证通过（见 `thetaverse分析输出/`）。

## 工作站/WSL2 上从 16S 测序数据到 qza 的标准流程（QIIME2 2024.10 amplicon）
```bash
# conda 环境
conda activate qiime2-amplicon-2024.10

# 1. 导入 EMP 格式 16S 测序数据
qiime tools import --type EMPSingleEndSequences \
  --input-path seqs/ --input-format EMPSequences \
  --output-path demux-paired-end.qza   # 双端用 EMPPairedEndSequences

# 2. 拆条码
qiime demux emp-single --m-barcodes-file barcodes.tsv \
  --i-seqs demux-single-end.qza --p-revcomp-mapping-barcodes \
  --o-per-sample-sequences demux.qza --o-error-summary-details demux-summary.qzv

# 3. 去噪（dada2）
qiime dada2 denoise-single --i-demultiplexed-seqs demux.qza \
  --p-trim-left 0 --p-trunc-len 120 \
  --o-representative-sequences rep-seqs.qza --o-table table.qza --o-denoising-stats stats.qza

# 4. 物种分类（预训练分类器 gg-13-8）
qiime feature-classifier classify-sklearn \
  --i-classifier gg-13-8-99-nb-classifier.qza \
  --i-read rep-seqs.qza --o-classification taxonomy.qza

# 5. 建树
qiime phylogeny align-to-tree-mafft-fasttree \
  --i-sequences rep-seqs.qza --o-rooted-tree rooted-tree.qza
```

## 回传后的本机 ThetaVerse 分析
将 table.qza / taxonomy.qza / rooted-tree.qza / sample_metadata.tsv 放入
`A2_16S_qiime2/artifacts/`，重跑 `python scripts/run_A2_16S_qiime2.py` 即得
落表 + 下游（α/β 多样性、PCoA、分组检验）全套输出。

## 本机已验证的部分（真实 qza，非伪造）
- 输入 artifacts：QIIME 2 官方 moving-pictures 教程产物，docs.qiime2.org 下载
  （md5 记录见 `thetaverse分析输出/stats_A2.json`）。
- thetaverse `read_qiime2_bundle` 会校验每个 qza 的语义类型/UUID/SHA-256，
  非 QIIME 2 生成的伪造文件无法通过校验。
- sample_metadata.tsv 源站 data.qiime2.org 本机网络不可达（连接超时，2026-10-20 实测），
  本次以 metadata=None 运行；分组列（body-site）待元数据可达后重跑即得分组检验。
