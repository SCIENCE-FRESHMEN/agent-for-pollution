# 文献批量下载工具包 · 使用说明（机构订阅版）

> **给谁用**：有高校机构订阅账号的同学（默认以北京大学为例，任何 CARSI 高校都行）。
> **做什么**：把几千篇文献的 DOI 清单**自动逐篇下载**成 PDF，按期刊分文件夹保存。
> **要动手多少**：装一次 Python、填一次配置、首次登录点几下鼠标，之后全部自动，可以挂机过夜。
>
> 本文档写给没有编程基础的同学，每一步都写得很细；有经验的同学直接看
> 「三、快速开始（熟练版）」即可。

---

## 〇、先回答两个最常见的问题

**Q：config.json 在哪？**
就在工具包文件夹里，文件名是 `config.json`，和「开始下载.cmd」**在同一个文件夹**。
用「记事本」打开它：右键点击文件 → 打开方式 → 记事本。

**Q：需要连学校的 VPN 吗？**
**不需要。** 本工具用的是 CARSI 机构登录（就是你在知网/出版社页面选“上海财经大学/
北京大学”那种登录方式），在家庭网络下直接可用。当然你连着校园 VPN 也没问题。

## 一、开始之前，你需要准备

| 需要 | 说明 |
|---|---|
| Windows 电脑 | 10 / 11 均可 |
| Python 3.9 或更新 | 下面第 1 步教你装 |
| Google Chrome 浏览器 | 工具会开一个**专用** Chrome 窗口，不影响你日常用的浏览器 |
| 本校的统一认证账号密码 | 就是登录学校图书馆/信息门户的账号 |
| 总时间 | 首次准备约 15 分钟；下载挂机 1~2 天（可随时暂停/续跑） |

## 二、手把手教程（新手版）

### 第 1 步：安装 Python（只做一次）

1. 打开网址：**https://www.python.org/downloads/**
2. 点黄色大按钮 **Download Python 3.x.x**，下载后双击安装包。
3. **关键一步**：安装第一屏最下面，勾选 ☑ **Add python.exe to PATH**
   （不勾后面会报“python 不是内部或外部命令”）。
4. 点 **Install Now**，等它装完，关掉。
5. 验证：按 `Win + R`，输入 `cmd` 回车；在黑窗口里输入：
   ```
   python --version
   ```
   显示 `Python 3.9` 以上版本号即成功。

### 第 2 步：解压工具包

把拿到的 `pku-lit-toolkit` 压缩包，右键 → 全部解压，放到一个**路径简单**的地方，
例如 `D:\pku-lit-toolkit`（不要放在桌面多层文件夹里，路径里尽量不要有中文和空格）。

### 第 3 步：填写 config.json（唯一要编辑的文件）

打开工具包文件夹，找到 **config.json**（和「开始下载.cmd」同级），
右键 → 打开方式 → **记事本**。把开头这几行改成你自己的信息：

```json
"institution_zh": "北京大学",
"institution_en": "Peking University",
"username": "2200010000",
"password": "你的密码",
"email": "2200010000@stu.pku.edu.cn",
```

逐项说明：

| 字段 | 填什么 | 注意 |
|---|---|---|
| `institution_zh` | 学校中文名 | 机构检索时用，照抄学校官方全称 |
| `institution_en` | 学校英文名 | 同上 |
| `username` | 学号/工号 | 学校统一认证的账号 |
| `password` | 统一认证密码 | **不想明文存密码？把这行改成 `""`（空），首次登录改为手动输入**，其余功能完全一样 |
| `email` | 学校邮箱 | 出版社通过邮箱域名识别学校，建议如实填写 |

改完保存（Ctrl+S），关闭记事本。
> 提醒：改的时候**不要删掉**每个字段外层的英文双引号，不要动冒号和逗号。

### 第 4 步：确认下载清单（不用改可跳过）

- 默认清单是 `data\missing_sweep.csv`：本项目缺文 **4735 篇**，直接用即可。
- **多人分工**（推荐，人越多下得越快）：
  1. 组织者在 cmd 里运行（数字=参加人数）：
     ```
     python code\split_queue.py 5
     ```
     会生成 `data\queue_part1.csv`、`queue_part2.csv` …（每人一份，互不重复）。
  2. 你领到第 k 份，就把 config.json 里 `"queue"` 的值改成
     `"data/queue_partk.csv"`。
- 想下**自己的**清单？准备一个带 **DOI 列**的 Excel/CSV，然后：
  ```
  python code\make_queue.py 你的清单.xlsx
  ```
  再把 config.json 的 `"queue"` 改成 `"data/my_queue.csv"`。

### 第 5 步：双击「开始下载.cmd」

它会自动：检查并安装 Python 依赖（首次约 1~3 分钟）→ 弹出一个**专用 Chrome 窗口**
→ 尝试自动机构登录。这个黑窗口是控制台，**不要关它**，进度都在里面。

### 第 6 步：首次登录（只有一次，约 2 分钟）

按控制台的提示操作，分两种情况：

- **情况 A：自动化成功**——什么都不用做，它自己登好了。
- **情况 B：提示人工登录**——在弹出的 Chrome 里：
  1. 点击页面上的 **Access through your organization**（或“机构登录 / Sign in”字样）；
  2. 检索框输入学校名（如 `Peking`），回车后**点选你的学校**；
  3. 跳到学校统一认证页，输入账号密码（有验证码/扫码就按学校要求完成）；
  4. 回到 ScienceDirect 页面，能看到文章全文（出现 View PDF）即为成功；
  5. 回到控制台，**按回车**继续。
- 之后可能再弹 Springer / Wiley / Taylor & Francis 三个登录页，
  **强烈建议**每家都做一次机构登录（每家约 1 分钟，都是“机构登录→选学校→输密码”）。
  不需要的社可以不管（对应文献会记为无权限）。

### 第 7 步：挂机等它跑完

- 之后完全无人值守。**别关 Chrome、别关黑窗口、别让电脑睡眠**
  （设置 → 系统 → 电源，把“睡眠”改为“从不”；屏幕关闭没关系，建议插电源）。
- 随时看进度：
  - 控制台每 50 篇打一行汇总；
  - 或打开 `logs\sweeper_log.csv`（每篇一行的流水账）。
- 下载结果在 **`downloads\`** 文件夹，按期刊分子文件夹，文件名就是 DOI。

**预计耗时**：约 10~20 秒/篇（刻意放慢防封禁），4735 篇约 1~2 天。
**随时可停**：直接关掉窗口即可；下次再双击「开始下载.cmd」会自动跳过已下载的，断点续跑。

### 第 8 步：完成之后

1. 工具自动生成 **`下载报告.md`**（记事本可打开）：按期刊统计 + 未成功清单及原因。
2. **把结果回传给组织者**：右键 `downloads` 文件夹 → 压缩成 zip → 发给组织者。
   组织者把大家的 zip 解压到同一个文件夹即可自动合并（文件名就是 DOI，重复会自动覆盖为同一篇）。

## 三、快速开始（熟练版）

```
1. pip install -r requirements.txt        # 国内慢可加 -i https://pypi.tuna.tsinghua.edu.cn/simple
2. 编辑 config.json（机构/账号/邮箱；密码可留空）
3. python code\split_queue.py N           # 多人分工时
4. 双击 开始下载.cmd → 首次人工登录一次 → 挂机
5. 结果：downloads\ + 下载报告.md；断点续跑直接重跑
```

## 四、文件夹结构（哪里是什么）

```
pku-lit-toolkit\
├── 开始下载.cmd        ← 双击运行（唯一入口）
├── config.json         ← 唯一要编辑的文件（学校/账号/清单路径）
├── requirements.txt    ← Python 依赖清单（自动安装）
├── README.md           ← 本文档
├── code\               ← 全部源码，可自行审阅
│   ├── supervisor.py   总控看门狗：登录→下载→自动重登→限速冷却→报告
│   ├── auth.py         机构登录（自动尝试，失败转人工）
│   ├── sweeper.py      逐篇下载器（单页面串行+防封禁节奏）
│   ├── captcha.py      滑块拼图验证码自动求解（求解不了会转人工）
│   ├── chrome_ctl.py   专用 Chrome 启动与自愈
│   ├── split_queue.py  多人分工拆分清单
│   ├── make_queue.py   把任意 Excel/CSV 清单转成下载队列
│   ├── report.py       生成下载报告
│   └── common.py       公共工具
├── data\
│   ├── missing_sweep.csv   默认队列：4735 篇缺文（DOI 清单）
│   ├── journal_map.json    DOI→期刊名 映射（用于分文件夹）
│   ├── pii_map.json        DOI→Elsevier PII 映射（缺的自动向 Crossref 补）
│   └── queue_part*.csv     分工时生成的子队列
├── downloads\          ← 下载结果（按期刊分文件夹）
└── logs\               ← 日志、浏览器专用配置、断点记录（不用管）
```

## 五、常见问题（按症状查）

**1. 双击后闪退 / 提示 “python 不是内部或外部命令”**
安装 Python 时没勾 *Add python.exe to PATH*。重装 Python 并勾上，或参考
第 1 步第 3 点。

**2. 提示 "[X] config.json is not configured yet"**
config.json 里还有「在这里填」字样——说明账号/邮箱没填完整，按第 3 步填好再运行。

**3. pip 安装依赖很慢或失败（网络超时）**
用国内镜像手动装，在 cmd 里执行：
```
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```
装好后再双击「开始下载.cmd」。

**4. 提示找不到 Chrome**
你的 Chrome 没装在默认位置。右键 Chrome 快捷方式 → 属性 → 复制“目标”里的路径，
粘贴到 config.json 的 `"chrome_path"`（注意路径里的 `\` 要写成 `\\`）。

**5. 自动登录总是失败，每次都要手动？**
学校认证页样式各异（有的要扫码/短信双因子），自动化填不了很正常。
密码留空 + 人工登录是最稳的用法；登录一次后会话能保持很久，过期了工具会再叫你。

**6. 为什么有些文献下不到？**
出版社页面显示贵校**未订阅**该期刊（报告里状态 `blocked:*`）。这是版权墙，
正规渠道无解：只能请有订阅的机构同学帮忙，或走图书馆馆际互借。
工具绝也不会去绕过付费墙，请勿要求它这么做。

**7. 控制台出现 “冷却 25 分钟”？**
被出版社临时限速了，工具自动休息后继续，不用管。若频繁出现，把 config.json
里 `pace_min/pace_max` 调大（如 10 和 15），更稳。

**8. 中途电脑睡眠/关机/程序被关？**
重新双击「开始下载.cmd」即可，已下载的自动跳过。

**9. 想看下了多少篇了？**
打开 `downloads\` 数文件夹，或看 `logs\sweeper_log.csv` 行数，或看控制台进度行。

**10. 下载的文件名为什么是乱改过的 DOI？**
`/` 等符号不能出现在 Windows 文件名里，所以 DOI 的 `/` 被换成了 `_`
（如 `10.1016/j.watres...` → `10.1016_j.watres...`），内容不受影响。

## 六、安全与合规（请务必阅读）

- 本工具**只使用贵校的正规机构订阅**从出版社官网下载，不使用、也不应被用于
  绕过付费墙的任何非正规渠道；
- 账号密码仅保存在本地 config.json（可留空改为手动登录）。**请勿把填好密码的
  config.json 发到网上或发给他人**；
- 下载的 PDF 仅限个人学习科研使用，请遵守学校数据库的使用协议，**勿批量传播**；
- 请控制节奏（工具已内置放慢机制），不要对出版社网站造成困扰。

## 七、给组织者/技术同学的技术备注（可跳过）

- 机制：真实 Chrome + CDP（127.0.0.1:9222）+ `Browser.setDownloadBehavior`
  下载到 `logs\staging`，文件系统轮询校验（`%PDF-` 文件头 + 大小稳定）后才
  移动入库——规避浏览器下载事件竞争产生的 0 字节文件（实战踩坑验证）。
- 状态码：`downloaded` / `skipped_exists` / `blocked:*`（无权限，永久）/
  `failed_no_pdf:*`（疑似限速，自动冷却重试）/ `failed_other:*`（异常，自动重试）。
- 本包在上海财经大学环境实战验证：Elsevier/Springer/Wiley/Taylor & Francis
  四社的 CARSI 登录与批量下载链路可用；更换机构仅需改 config.json。
- 组织者合并多人结果：把各人 `downloads\` 下的**期刊子文件夹**内容并到同一目录即可，
  文件名为 DOI（`/`→`_`），天然去重。
